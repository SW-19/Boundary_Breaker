# Fancy Leo — AI & Data Science Portfolio

A bilingual (English / Chinese) personal portfolio built with React, TypeScript, Tailwind CSS, Framer Motion and Lucide React.

## Run locally

```bash
npm install
npm run dev
```

Build for production:

```bash
npm run build
npm run preview
```
